# RTL Design & Functional Verification

Currently building practical experience with Verilog, SystemVerilog, UVM, and protocol-based verification.

## Focus Areas

- RTL design and digital logic
- SystemVerilog and UVM-based functional verification
- Assertions (SVA), functional coverage, and scoreboards
- AMBA interfaces and serial protocols
- Simulation, debugging, and verification planning
